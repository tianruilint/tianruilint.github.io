01 RTL and verification · Jul 2026

One ISA.
Two microarchitectures.

Single-cycle and five-stage SystemVerilog cores for a 37-instruction RV32I subset. They share the ALU, decoder and register file. The pipeline adds EX/MEM and MEM/WB forwarding, a WB-to-ID bypass, one-cycle load-use stalls and two-slot flushes on taken branches and jumps.

A small model of the hazard rules, written for this page. The measured numbers below come from the RTL on Verilator.

Same programs, both cores

Cycles to retire each workload under a zero-wait memory model. The pipeline matches C = N + 4 + L + 2R exactly.

Cycle counts are not execution time. The pipeline spends more cycles and runs each one much faster; the clock comes from the layout below.

How it was checked

  • 74cocotb cases passing across 17 Verilator targets
  • 64generated programs compared against an independent Python RV32I interpreter after every retired instruction
  • 94.2%line coverage, with 98.3% branch, 100% expression and 97.5% toggle

Scope. No CSRs, exceptions or interrupts. External zero-wait memory. Every uncovered point is an unreachable default or a documented unsupported misaligned access.

The limiting path was in my RTL, not in the flow.

STA showed the EX branch redirect fanning out as flush to about 200 ID/EX flops, and a reset to data_write_data feed-through from gating the store data. I changed flush and bubble to clear only the valid and control bits, and reset to gate only the write enable. At 1.4 ns the worst slack moved from −0.006 to +0.005 ns.

03 SoC integration · Jul – Sep 2026

When a core
meets a system.

A simulation SoC that runs bare-metal C on the open-source FRISCV RV32IM core. I added a DMA engine, an AXI-Lite-to-APB bridge, an APB timer, the top level and address map, the firmware and the verification environment.

    Bugs found in the third-party RTL

    Stress-testing the system exposed defects in the reused CPU and cache. Each fix is a separate patch with a test that fails before and passes after. I reported six upstream.

      Upstream status as of 8 Nov 2026.

      Verification

      • 9firmware-driven system scenarios on Verilator, with random wait states, backpressure and reset during DMA
      • 48interrupt-versus-fault collision cases, plus 60 load/store-fault cases with younger instructions in flight
      • 60/60runs of a UVM environment for the APB timer, catching all 5 injected RTL bugs

      Scope. Simulation only. The 128-bit bus is the upstream single-beat AXI-Lite-style extension, not standard AXI4-Lite, and there are no bursts. No FPGA, synthesis or timing results for the SoC.
